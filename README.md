# Piriápolis Flood Screening

Static, client-side flood-exposure screening tool for Piriápolis, Uruguay.
Enter a padrón (or address/pin) to get storm-surge, pluvial-ponding, and
fluvial (HAND) screening flags for a parcel.

**Screening only — not an official floodplain determination.** The legal
zona-inundable designation is applied case-by-case by the Intendencia de
Maldonado (Decreto 3733/999) at permit time. Boundary cases should be
confirmed with an agrimensor or the Intendencia.

Data: IDEuy 1 m urban MDT + DNC parcel layer. Built with Claude (Tardis Software).
